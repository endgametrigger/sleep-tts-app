A simple text-to-speech web application using OpenAI's TTS API for creating soothing bedtime audio.

## Setup

1. Clone this repository
2. Copy `.env.example` to `.env`
3. Add your OpenAI API key to `.env`
4. Run the application

## Features

- Clean, simple interface
- OpenAI TTS with soothing "Shimmer" voice
- Adjustable speed for relaxation
- Copy and paste text input
- Play/pause controls

## Cost

Approximately $0.015 per 1,000 characters (~$0.50/month for daily use)
